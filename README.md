# Tip Calculator

Fair tips and split bills, worked out instantly.

Free calculators and plain guides, built as a static site for GitHub Pages. No build step, no external libraries: every page uses inline CSS and JavaScript only.

## Structure

- `index.html` - home page with the main calculator
- `tools/` - four working calculators
- `guides/` - twenty guides with worked examples
- `images/` - one image per guide
